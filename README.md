# ChartForge · 图表库 + 大屏工作台

一个用 Vue 3 + ECharts 做的可视化工作台，主流程分两步：**先在图表库里做好图表，再把图表拖进大屏拼装**。

图表库是图表的正式产地：新建、选类型、调参数、填数据、看预览都在这里完成，保存后得到一张带缩略图、可搜索、可分类的卡片。
大屏是拼装容器：新建一块画布，把图表库的卡片拖上去，调位置、尺寸、层级，最后全屏演示或导出。

## 主流程

```
图表库 /charts  ──拖拽──▶  大屏 /workbench/:id  ──▶  演示 /play/:id
   │                            │
   └── 点击卡片 /charts/:id     └── 大屏库 /screens 管理所有大屏
       （编辑类型/参数/数据）
```

1. **做图表**：`/charts` 点「新建图表」，选 6 种类型之一，进入 `/charts/:id` 编辑页
2. **拼大屏**：`/screens` 新建大屏（内置 1080p / 2K / 竖屏等预设）→ 进入工作台 → 从左侧图表库把卡片拖到画布
3. **演示 / 交付**：`/play/:id` 全屏演示，或导出图片 / JSON

> 大屏里的图表是图表库资产的**独立副本**（深拷贝 spec），改大屏里的图表不会影响图表库，删图表资产也不会让已上屏的图表消失；
> 选中图表时右侧会显示「来源：xxx」，可一键跳回源图表。想把大屏里的图表回收进库，用「另存为图表资产」。

## 功能

### 图表库
- 6 种图表：折线图、柱状图、饼图、地图（中国省级）、散点图、雷达图
- 新建即自带示例数据，打开就能看到图，不用先填表
- 卡片缩略图由真实 ECharts 渲染（关闭动画取终态、白底、16:9），改动后防抖自动更新
- 搜索 / 按分类筛选 / 标签筛选，批量改分类、批量删除
- 编辑信息（名称、分类、标签）、复制、导出单个图表 JSON

### 图表编辑页（`/charts/:id`）
- 参数面板按 `title / legend / tooltip / grid / xAxis / yAxis / series` 分组，带中文说明
- 数据表格编辑（饼图填名称+数值，散点填 X/Y，雷达按指标展开），支持 TSV 粘贴
- 撤销 / 重做：`Ctrl+Z` / `Ctrl+Y`（或 `Ctrl+Shift+Z`），顶栏也有按钮
- 切换图表类型会重置参数与数据（有二次确认）
- 设置拖入大屏时的默认尺寸

### 大屏工作台
- 1920×1080 / 2560×1440 / 1920×1200 / 1600×1200 / 1080×1920 等画布预设，可自定义背景
- 图表、文本、图片、形状四类元素，支持拖拽、缩放、旋转、对齐、分布、组合、锁定、隐藏、层级调整
- 吸附辅助线与网格
- 大屏缩略图、命名、分类、标签、复制、导出 JSON
- **实时数据**：图表可绑定 HTTP 接口（地址 + 间隔 ≥5 秒 + `dataPath` 取值路径）。载荷支持二维表（首行表头）、**对象数组**、纯数值数组和完整图表数据；路径支持 `a.b`、`rows[0].value`、`rows[*].value`（通配拍平成数组）。**同一接口被多张图表引用时一轮只发一次请求**（全局数据源中心：合并 + 单飞 + 失败退避 + 页面隐藏暂停），配置面板带「测试连接」预览，拉取失败时**画面保留上一份数据并标红提示**
- **接口设置页（`/settings`）**：统一配置接口前缀 `baseUrl`、公共请求头（token 默认打码）、公共查询参数、默认间隔与超时并「探活」；图表里只写相对路径（如 `/api/sales`），请求时自动拼接。选中大屏图表后可「连接 / 调试台」两步走：调试台显示 HTTP 状态码、耗时、`dataPath` 命中行数与字段清单、原始响应，并可「用这份数据填充图表（快照）」。导出的 JSON 默认把请求头里的令牌替换成 `***` 选中图表后的「加工」Tab 可对接口数据做**行过滤（9 种运算符）/ 选列 / 排序 / 取前 N / 字段映射**，还能把长表（一行一个组合）按系列字段**透视成多系列**；调试台会显示「原始 24 行 → 过滤 12 行 → 取前 10 行」每一步的行数。
- **导出可交付产物**：大屏库卡片上的「导出」按钮会生成**能直接打开、能部署**的产物——zip 目录包（`index.html` + `assets/` + `manifest.json` + 许可证 + `serve.sh`）或单文件 HTML。产物不依赖 ChartForge：解压丢到任意静态服务器即可，双击 HTML 也能看；自带严格 CSP（`default-src 'none'`、零外链、零 eval）、用户文本全部转义、图片地址白名单、目录包脚本带 SRI 完整性校验，`manifest.json` 记录每份文件的 SHA-256，并保留 ECharts 的 Apache-2.0 声明。默认是**静态快照且不含令牌**（实时轮询与多屏轮播包在后续版本）
- **布局模板**：新建大屏可选「空白 / 2×2 四宫格 / 1 主 2 辅 / 三列等分 / 顶部横幅 + 四宫格」，模板会在画布上铺好占位框，图表拖上去占位框自动消失（演示时不显示）
- 演示模式全屏播放（Esc 退出）
- **多屏轮播**：大屏库「轮播演示」勾选多块大屏并设置切换间隔（3–600 秒），自动循环播放；演示中 `←` / `→` 手动切屏、`空格` 暂停/继续、底部圆点指示进度

### 数据与存储
- 全部数据存在浏览器 `localStorage`（key `chartforge.workspace.v1`），刷新不丢，自动保存
- 整库导入 / 导出 JSON；旧版本数据会自动规范化补齐，不会打不开

## 技术栈

Vue 3.5 · TypeScript 5.9 · Vite 8 · Pinia 3 · ECharts 6 · Vitest 3

UI 全部是自写的轻量组件（`src/shared/ui`），没有引入组件库；ECharts 按需注册且拆成独立 chunk，首屏只加载应用代码，图表引擎在进入编辑器/图表库时异步补齐。

## 快速开始

需要 Node.js ≥ 20 和 pnpm。

```bash
pnpm install
pnpm dev        # 开发服务器
pnpm build      # 生产构建，输出到 dist/
pnpm preview    # 预览构建产物
pnpm typecheck  # 类型检查
pnpm test       # 单元测试
```


### 本地测试接口（mock server）

想试实时数据 / 调试台 / 数据加工，又不想先去对接真接口？仓库自带一个零依赖的 mock 服务：

```bash
pnpm server        # 起在 http://localhost:8787，浏览器打开就是接口目录页
```

然后在 **接口设置** 里把 baseUrl 填成 `http://localhost:8787`，图表数据源里只写相对路径即可，
例如 `/api/charts/line`（折线）、`/api/charts/pie`（饼图）、`/api/sales/wrapped` 配 `dataPath=data.rows`。
六种图表各有接口，另外还有 POST、Bearer 鉴权、超时、随机失败、超大载荷等演练接口。

接口清单、参数、每个接口适合哪种图表，见 **[server/README.md](server/README.md)**。

## 目录结构

```
src/
├─ views/                 # 页面：图表库、图表编辑、大屏库、工作台、演示
├─ workbench/             # 工作台组件（画布、图层面板、属性面板、缩略图渲染）
│  └─ panels/             # 右侧属性面板：图表配置 / 数据表 / 位置尺寸 / 样式 / 画布
├─ core/
│  ├─ model/              # 数据模型、规范化、路径读写
│  ├─ chart/              # ECharts option 构建、示例数据、按需注册
│  ├─ geometry/           # 吸附、命中测试、坐标变换
│  ├─ history/            # 撤销重做栈
│  ├─ storage/            # localStorage 持久化、缩略图
│  ├─ export/             # 产物导出（快照/HTML/zip/manifest，运行时字符串）
│  ├─ live/               # 实时数据源（轮询、数据源中心）
│  ├─ live/apiSettings.ts  # baseUrl 拼接与请求合成（含全局/图表级合并）
│  └─ live/probe.ts       # 调试台探活与字段推断
├─ stores/                # Pinia：workspace（图表库/大屏库）、document（当前大屏）、ui
├─ shared/                # 拖拽常量、主题、通用 UI
└─ assets/geo/            # 中国地图数据
```

## 几点说明

- **地图不着色**：`china.json` 里的区域名带后缀（`广东省`、`北京市`），数据里的 `name` 要和它完全一致，示例数据已按此填写。
- **缩略图是旧的 / 和图表对不上**：缩略图算法有版本号，打开图表库会自动重算过期缩略图；也可以在编辑页改动一下让它在 800ms 后重生成。
- **页面报 `Cannot access 'xxx' before initialization`**：`<script setup>` 里带 `immediate: true` 的 watch 会在 setup 阶段立刻执行，它写入的 ref 必须声明在这行**之前**。`tests/setup-order.spec.ts` 会静态扫描所有组件兜住这类顺序错误。
- **安装报 `ERR_PNPM_IGNORED_BUILDS`**：仓库里的 `pnpm-workspace.yaml` 已配好 `allowBuilds`，直接 `pnpm install` 即可。
- **`src/assets/screens/`**：运行时导出的 JSON 产物，已在 `.gitignore` 中忽略。
- **体积**：构建产物 `echarts`（约 647 KB）/ `vue-vendor`（约 96 KB）各自独立 chunk，`index` 首屏仅约 5 KB；gzip 后全站约 320 KB。main.ts 不再全局注册 ECharts，`/charts` 的缩略图迁移用动态 `import()`，列表先出、图表后到。
