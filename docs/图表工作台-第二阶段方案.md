## 一、背景与目标

第一阶段把工作台收敛为「单图 + 装饰 + 图表库 + 演示」。第二阶段把粒度抬到**大屏**：一张固定尺寸的画布上摆多个图表与素材，形成可直接演示的看板。

**一句话目标**：用户能从图表库里挑几个做好的图表，拖进一张 1920×1080 的大屏，排好版，5 分钟内进入演示模式并保存进大屏库。

与第一阶段的差异（关键）：

| 维度 | 第一阶段 | 第二阶段 |
|---|---|---|
| 画布主体 | 一张画布 = 一个图表 | 一张画布 = 大屏，可含任意多个图表 |
| 图表来源 | 新建即入画布 | 新建 / 从图表资产库拖入副本 |
| 资产层级 | 屏即资产 | 图表资产（单图）与大屏资产（多图）两层 |

## 二、范围

### 2.1 本阶段包含

| 模块 | 内容 |
|---|---|
| E 图表资产库 | 把单图保存为可复用的图表资产；列表、搜索、分类/标签筛选、缩略图、编辑信息、复制、删除、导出、拖拽源 |
| F 大屏拼装 | 固定像素画布；从左栏拖入图表资产生成独立副本；拖入文本/图片/形状；多选、对齐吸附、对齐与等距分布、组合、图层 |

### 2.2 本阶段不包含

- 实时数据与接口（继续假数据）。
- 后端、账号、云端同步、分享链接、模板市场。
- 图表与大屏之间的**强引用**（大屏里的图表一律是副本，不跟随资产更新）。
- 大屏模板/自动排版引擎、响应式断点、画布内嵌套容器。
- 导入（单图 JSON / 工作区 JSON 导出继续保留）。

## 三、核心概念

- **图表资产（ChartAsset）**：一份可复用的单图定义 = `spec`（类型 + option 覆盖层 + 假数据）+ 缩略图 + 元信息。取自 `Workspace.assets`。
- **大屏（Screen）**：一张固定尺寸画布 = `canvas`（宽高 + 背景）+ `items`（多个图表项与素材项）+ 缩略图 + 元信息。取自 `Workspace.screens`。
- **图表项（ChartItem）**：大屏上的一个图表实例，持有 `spec` 的**深拷贝**与自己的 `frame`。与源资产无引用关系。
- **副本语义**：拖入、复制、粘贴都产生新 `id` 的深拷贝；改大屏里的图表不影响资产，改资产也不影响已放置的图表。

## 四、用户流程

### 4.1 制作并保存一个图表资产

1. 大屏编辑页左栏「图表类型」点击类型 → 画布中新增一个图表项（居中，叠放偏移）。
2. 选中该图表项 → 右栏「参数 / 数据」配置并编辑假数据。
3. 在检查器点击「保存到图表库」，填写名称、分类、标签 → 生成缩略图，写入 `assets`。

### 4.2 拼装一张大屏

1. 大屏库点击「新建大屏」→ 选尺寸预设（16:9 FHD/QHD、16:10、4:3、9:16、21:9、自定义）+ 可选锁定宽高比 → 进入编辑页。
2. 左栏「图表库」tab 列出图表资产（缩略图 + 名称 + 类型 + 分类/标签），搜索/筛选后可拖到画布任意位置落位（拖动显示半透明预览，落位自动选中）。
3. 左栏「素材」拖入文本 / 图片 / 形状。
4. 多选后用对齐工具条对齐、等距分布；拖动时显示参考线并在画布边缘/中心/其他元素边缘吸附（按住 Alt 临时关闭）。
5. 图层面板排序、锁定、隐藏、重命名、组合/解组。
6. 「保存到大屏库」→ 生成缩略图与元信息。

### 4.3 复用与演示

1. 大屏库搜索 / 分类 / 标签筛选，卡片可：编辑、演示、复制、导出（JSON）、编辑信息、删除（需确认）。
2. 演示模式全屏展示（等比缩放居中、黑底留边、Esc 或右上角浮动按钮退出，闲置 3 秒按钮淡出）。

## 五、界面与交互

### 5.1 页面结构

| 路由 | 页面 | 作用 |
|---|---|---|
| `/` | 大屏库 | 大屏卡片网格、新建、搜索/分类/标签、卡片操作、演示入口 |
| `/charts` | 图表库 | 图表资产列表、搜索/筛选、编辑信息、复制、删除、**拖拽源**（待确认 Q1） |
| `/workbench/:id` | 大屏编辑 | 三栏 + 顶栏（沿用第一阶段布局与样式） |
| `/play/:id` | 演示 | 全屏只读，大屏与单图通用 |

顶部导航：图表库 / 大屏。

### 5.2 大屏编辑页左栏

```
┌ 图表类型 ─ 6 个 chips（点击 = 新增图表项，可拖入指定位置）
├ 图表库 ── 搜索 + 分类/标签筛选 + 资产缩略图列表（拖拽源）
├ 素材 ──── 文本 / 图片 / 形状
└ 图层 ──── 元素列表（排序、锁定、隐藏、重命名）
```

- 左栏四个 tab；选中元素不同，右栏自动切到对应面板（画布属性 / 图表参数+数据 / 文本 / 图片 / 形状）。
- 画布已有多个图表时，点击「图表类型」中的类型 = 再新增一个（撤回第一阶段的单图约束，见 D11）。

### 5.3 关键交互（新增或收紧）

| 功能 | 交互 |
|---|---|
| 拖入图表资产 | 拖到画布落位；落位为深拷贝副本；同名图表自动追加「副本2/3」 |
| 图表聚焦编辑 | 双击图表进入聚焦：其余元素降透明度不可交互，右栏 = 参数+数据；Esc 或点击空白退出 |
| 对齐工具条 | 多选 ≥2 时出现：左/水平居中/右、上/垂直居中/下、水平等距、垂直等距 |
| 缩放 | 滚轮以光标为锚点缩放（25%–400%）；Ctrl+0 适配窗口、Ctrl+1 100%；空格 + 拖动平移 |
| 越界策略 | 元素拖动/缩放/粘贴均不越出画布；缩小画布时弹确认：「保留原位（裁切）」或「等比适配全部元素」 |
| 图表类型切换 | 选中图表项后可在检查器切换类型（复用 `changeChartType`），保留原位与尺寸（待确认 Q4） |
| 保存到大屏库 | 顶栏主按钮；自动缩略图；名称/分类/标签对话框 |

## 六、数据与存储

### 6.1 模型（复用现有结构，仅补可选字段）

```
ChartAsset {                 // Workspace.assets（已在模型中）
  id, name, thumbnail,
  spec,                      // ChartSpec：type + option + data
  category?, tags[],         // 新增：与 Screen 一致的检索元信息
  defaultSize? { w, h }      // 新增：拖入大屏时的初始尺寸
  createdAt, updatedAt
}

Screen {                     // Workspace.screens（已在模型中）
  id, name,
  canvas { width, height, background },
  items[],                   // 多 ChartItem + Text/Image/Shape
  thumbnail?, category?, tags[],
  updatedAt
}
```

- 不新增集合、不改 `version: 1` 的迁移路径；`normalizeWorkspace` 对新字段做缺省兜底。
- 图表项不存 `assetId` 引用（副本语义），可选存 `sourceAssetName` 仅作展示用。

### 6.2 存储

- 继续 `localStorage`，key `chartforge.workspace.v1` 不变。
- 图片压缩沿用 `src/core/storage/imageCompress.ts`（长边 ≤2048、JPEG ≤2MB、质量阶梯）。
- 容量不足时顶栏提示保存失败（沿用现有降级路径）。

## 七、演示模式

- 与大屏通用：整张画布等比缩放到屏幕内并居中，比例不符留黑底边。
- 大屏内所有图表与素材一起渲染，无编辑 UI。
- 退出：Esc 或右上角浮动按钮（鼠标闲置 3 秒淡出），与第一阶段一致。
- 不设播放控制、不做自动轮播（如需要，列入第三阶段）。

## 八、验收标准与质量门

1. 从图表资产库拖入 2 个以上图表到一张大屏并完成排版，全过程 ≤5 分钟。
2. 拖入的图表是副本：改大屏内图表后，资产库中同名图表不变；改资产不影响已放置图表。
3. 大屏刷新页面后内容与元信息完整；旧数据（第一阶段保存的单图画布）可正常打开。
4. 元素无法拖出画布；缩小画布时两种策略（保留裁切 / 等比适配）都可用且结果可见。
5. 对齐与等距分布对多选生效，撤销可回退。
6. 演示模式可展示大屏全部内容并正确退出。
7. 质量门：`pnpm typecheck`、`pnpm test`、`pnpm build` 全通过，前端单测覆盖新增核心逻辑。
