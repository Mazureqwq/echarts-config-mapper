# DataV-lite 布局底板与背景素材设计稿

> 状态：方向已在对话中确认；等待用户审阅本规格。规格获批前不进入实现计划或修改产品代码。

## 目标

为 ChartForge 的设计库增加一组受控、离线可用的 DataV 风格布局底板与可单独插入的背景装饰素材，帮助用户快速建立大屏的视觉分区；图表和数据组件仍由用户自行添加与摆放。

## 背景与现状

- DataV 7.0 的设计库把画布底色与布局素材区分：套件提供主视觉布局、文字/色彩规范，素材中另有背景图、背景框和装饰条；素材可预览后点击或拖拽到画布。
- ChartForge 已有独立的画布背景设置（颜色/渐变/图片）、屏幕槽位模板、设计库主题/复用区块/本地图片；深色主题画布色为 `#12161d`。
- 现有 `SCREEN_TEMPLATES` 提供 `main-side` 与 `grid-2x2` 的几何槽位。新功能复用其槽位几何，不另造布局算法，也不取代创建大屏时的占位模板。

## 已确认范围

### 首批风格与资源

只做适配“监控大屏 · 深色”主题的一套本地素材，不新增浅色或其他风格包。首批包括：

1. **主辅分栏**：复用 `main-side` 的一主两辅槽位几何，为每个区域生成深色面板底/边框，并提供顶部标题区域装饰。
2. **2×2 数据区**：复用 `grid-2x2` 的四区几何，为各区域生成一致的面板底/边框与轻量角标。
3. **单件素材**：一个信息面板框、一个标题带、一个角标/装饰条素材，可单独插入。

版式卡片和素材卡片使用本地轻量预览，显示用途；以点击添加和拖拽放置两种方式使用。设计库保留现有主题、可复用区块与本地图片素材。

### 画布与图层行为

- 整屏布局作为一组由现有 `ShapeItem` 与已注册装饰组件组成的本地 `ScreenItem` 项插入；插入时按当前画布宽高重新计算槽位比例。
- 将新布局放在当前屏幕图层栈底部，使用已有 `groupId` 关联本次插入，便于图层面板中识别/分组；不改变现有图表或组件的位置、大小、顺序和样式。
- 布局只增加分区底板与装饰，不创建图表、不移动已有组件、不填充数据、不写入新屏幕级 layout/theme 字段。
- 单件素材可按点击居中或按拖拽落点插入；背景素材按底层元素处理。
- 不修改 `canvas.background`。用户设置的画布底色继续由现有页面设置管理；新建大屏的默认 `#12161d` 也保持独立。
- 无当前大屏时复用设计库现有提示；未知素材 ID / 非法拖拽载荷不插入。

## 架构与边界

- 增加编译期、只读的背景素材/布局配方注册表：稳定 ID、名称、用途说明、本地预览 key、适配主题和 `createItems(canvas)` 工厂。所有 ID 和预览 key 都是显式白名单。
- 布局工厂复用 `templateSlots("main-side" | "grid-2x2", canvas)`，仅依槽位生成底层 shape/已有 `chartforge.section-title@1`、`chartforge.corner-frame@1` 等已有受控项，不引入新的注册组件或 export renderer。
- 点击与拖拽都调用同一插入 action；拖拽复用 `DESIGN_DND_MIME` 并校验 `kind` 与 ID。插入逻辑只消费编译期注册表，不从 payload 加载组件、HTML、CSS 或图片 URL。
- 当前 schema 已有 `ScreenItem`、`groupId`、shape/component 项与离线 exporter；不新增 persisted 字段、不做迁移、不更改 `buildPackagePayload` API。
- 预览不读取外部图片或 CDN；实际画布项由本地 shape 与已注册版本渲染，因此编辑器、播放预览和离线导出遵循相同的图层数据。

## 安全、兼容和失败状态

- 无网络资源、用户 HTML/CSS/脚本、运行时插件、动态 renderer 查找、`eval`、`new Function` 或 `innerHTML`。
- 所有装饰颜色来自固定的深色主题 token 或安全 hex；标题内容使用现有文本组件/文本节点。
- 插入前校验当前屏幕、布局 ID、画布尺寸和计算出的有限正数 frame；失败时不产生部分插入。
- 背景项必须低于既有图表/数据组件，避免拦截其选择和交互；本次插入的组可通过现有图层能力一起定位或删除。
- 旧工作区、基础素材、已有屏幕模板、画布背景、常规区块与 offline package 结构保持不变。

## 验收标准

1. 设计库显示两种深色整屏底板和三个可独立插入的素材；卡片均有本地预览、用途说明、点击和拖拽入口。
2. `main-side` 与 `grid-2x2` 底板按画布尺寸生成正确的区域边界；小尺寸或非法尺寸有确定安全结果。
3. 应用底板只新增分组的底层背景项，不改变已存在屏幕项的 frame、样式、数据绑定或相互顺序；画布 `background` 不变。
4. 单件素材点击/拖放及无屏幕提示正确；未知 ID/非法 payload 被拒绝，不执行任意内容。
5. 新插入的本地 shape/已注册组件在编辑器、预览、ZIP 和单文件离线导出一致；离线产物没有新增外部资源或网络请求。
6. 现有屏幕模板、主题、设计库资源、滚动条和 `#12161d` 默认画布色不回归；运行 `npm run typecheck`、全量 Vitest 与 `npm run build` 通过。

## 非目标

- 不做浅色及多主题素材套件，不做用户上传的布局包或第三方素材市场。
- 不做自动摆放/重排图表、不替换/移动现有组件、不覆盖画布背景色、不把槽位模板与装饰布局合并成新的屏幕 schema。
- 不做一键美化、自由 CSS、HTML、动画背景、外部素材下载或整屏模板重构。
