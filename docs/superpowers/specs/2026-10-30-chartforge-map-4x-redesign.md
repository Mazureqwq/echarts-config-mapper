# ChartForge 地图 4.0 重做方案

> 状态：范围已确认，进入分批实现。此文档是实施基线；不代表地图重做已完成。

## 已确认的产品范围

- 当前重做目标为基础 2D 平面地图与参考图式 2.5D 矢量挤出地图；真正 DEM/地形/WebGL 3D 与 3D 地球均暂缓。
- 参考 DataV 4.0 的容器/子图层工作流及用户所附参考图的立体省级地图视觉；同级子图层按路线图分批交付。
- 2.5D 立体感须来自真实省界矢量顶面、屏幕深度方向的侧壁/多层切片、明暗和高光；不是只靠 CSS `rotateX`，也不代表真实海拔。
- 首批地图范围为中国；只复用本地行政区 GeoJSON，编辑器、预览与离线导出不得请求在线瓦片或外部资源。
- 保持编译期受控图层注册，不引入运行时插件或用户代码，不使用 `eval`。
- 保留现有地图数据绑定语义：图层自己的绑定覆盖容器绑定；没有独立绑定时继承容器绑定。

## 当前实现盘点（重做基线）

- `chartforge.map-scene-flat` 与 `chartforge.map-scene-tilted` 共用 `MapSceneWidget.vue` 和 `MapSceneProps`。
- 图层类型仅有 `regionFill`、`geoScatter`、`geoHeatmap`、`geoFlow` 四类；容器只保存 `presentation`、`pitch` 与图层数组。
- 现有“斜面 2.5D”首版仅通过 CSS `perspective` / `rotateX` 表现；用户明确指出它不是所需的参考图式立体挤出效果，需以矢量厚度 POC 替换视觉主表达。
- ECharts 已注册内置 `china` GeoJSON；`src/assets/geo/china.json` 约 54 KB。仓库没有 DEM 高程资产；当前目标也不要求 DEM 或 WebGL 地形依赖。
- 当前地图 E2E 已验证数据绑定继承/覆盖、变量交互、刷新与离线 runtime；这些行为必须在替换渲染器后保持。

## DataV 4.0 对照原则

### 基础平面地图

容器配置参考：中心/缩放范围与默认级别、旋转/倾角、背景、坐标系、比例尺和地图交互。子组件按置顶/中间/底部组织，管理工作流包括添加、排序、显隐、复制、重命名、删除与逐层配置。

路线图需覆盖截图和官方目录中的：轮播标签、格网聚合、飞线、呼吸气泡、等值面、信息标签、自定义区域下钻、图标/矢量散点、帧动画、背景图片、符号聚合、轨迹线、栅格瓦片、点热力、中国国家边界、区域热力及底图层。ChartForge 的离线约束下，在线高德底图/在线栅格瓦片不能作为运行时依赖；以本地中国边界和本地素材/瓦片策略实现对应能力或清楚标为不支持。

### 参考图式 2.5D 矢量立体地图

容器负责视图/缩放、背景、立体厚度与方向；立体主体由本地省界多边形顶面、侧壁/层叠轮廓、底座阴影与边缘高光组成。用户数据标签、点、热力、飞线是压在顶面上的独立子图层。厚度不映射海拔，不采样 DEM；实现优先复用受控矢量渲染链。真实 3D 地形和 DEM 是后续另行批准的范围。

## 分批实施顺序

### M0 — 共同模型和离线资源契约

- 形成版本化地图容器/图层模型，提供旧 `presentation` / 旧四类图层的迁移与兼容测试。
- 图层定义按类型白名单注册，带分层区、默认名称、数据字段契约、样式 schema、交互事件和 renderer 能力声明。
- 统一图层排序、显隐、锁定、复制、删除、重命名、独立/继承绑定与撤销语义。
- 明确地图资源包格式、许可/来源说明、编辑器与离线 runtime 共用的资源解析契约。

### M1 — 基础平面地图 4.0

- 以本地中国 GeoJSON 为底，重做容器镜头/缩放/中心/旋转、拖拽缩放、区域 hover/click 与地理字段映射。
- 建立容器子组件管理器与置顶/中间/底部顺序；优先实现区域热力、点热力、矢量散点、飞线、信息标签和中国边界。
- 其余 2D 同级图层按 M3 扩充，不以不可用的占位选项冒充完成。

### M2 — 参考图式 2.5D 矢量挤出视觉 POC（当前目标）

- 以已有 `MapSceneWidget` 与本地中国 GeoJSON 验证矢量顶面、方向性侧壁/分层轮廓、底座阴影和边缘高光；不能将整体旋转倾斜作为唯一立体效果。
- 保证地图边界和 regionFill/散点/热力/飞线坐标共用同一投影；数据点、标签和信息框位于顶面之上，视觉顺序明确。
- 先做有限地区/全国样式视觉 POC，比较受控 SVG/Canvas/ECharts 内置实现；用户确认效果前不扩展成完整 M2。
- 不引入 DEM、随机高度、在线瓦片、WebGL 地形引擎或运行时插件；真 3D/真实地形延期，需新范围确认。

### M3 — 完整子组件目录

- 按功能族补齐 2D 与 2.5D 两种地图容器的其余子图层：聚合/等值面、下钻、图标与符号、帧动画/轨迹等；在线背景图/栅格瓦片不作为离线默认依赖。
- 每项须有可见渲染结果、受控样式、字段映射、状态/错误反馈、层级规则和测试；地图在线服务仅作为文档参考，不复制其网络依赖。

### M4 — 导出、迁移与体验验收

- 编辑器、预览和单文件 HTML/ZIP 离线 artifact 对几何、镜头、图层顺序、变量过滤和交互保持一致。
- 覆盖旧地图存档兼容、矢量侧壁裁切/缩放性能、编辑器与离线 runtime 一致性、离线资源体积。
- Playwright 覆盖容器视图、子组件管理、绑定继承/覆盖、真实变量切换、刷新保存及离线交互；单元测试覆盖投影/GeoJSON/矢量挤出边界/聚合与图层 schema，不包含 DEM 高度采样。

## 验收底线

1. 两种地图都由真实中国边界数据驱动，不得只靠 CSS 渐变/伪地图装饰。
2. 2.5D 立体地图必须由真实省界矢量生成可见顶面和侧壁/层叠厚度；不得只旋转平面，不得把视觉挤出误称真实地形，也不依赖 DEM。
3. 图层类型、名称在子组件管理列表中直接可见；层排序/分组/显隐、复制/重命名/删除和每层配置具有可发现的 UI。
4. 每层数据字段、数据绑定与错误状态可检查；无独立绑定继承容器绑定，独立绑定覆盖容器绑定。
5. 离线产物没有外部网络依赖；不新增运行时插件执行、远程瓦片请求或 `eval`。
