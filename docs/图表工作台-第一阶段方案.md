## 一、背景与目标

ChartForge 原本是一个单图配置工具：用户通过参数面板低代码配置 ECharts 图表，无需手写代码即可得到可直接使用的 `option`。

本阶段要把它扩展为「可个性化的图表制作与复用工具」：

1. **高度自定义、低代码**：配置面板调整参数，表格编辑数据，不需要写代码。
2. **个性化设计**：在图表自己的独立画布里，拖入文本、图片、形状、背景等素材，对图表做装饰和排版。
3. **保存与复用**：把做好的图表保存到图表库，之后可以搜索、复制、再次编辑。
4. **演示**：一键进入全屏演示模式查看效果。

**一句话目标**：用户在 5 分钟内，做出一个带装饰的图表，保存进图表库，并能在演示模式中全屏展示。

## 三、核心概念

- **图表（Chart）**：一个 ECharts 图表，包括类型、参数配置（option 覆盖层）和假数据。
- **素材（Decoration）**：画布上的文本、图片、形状、背景。
- **画布（Canvas）**：图表编辑的独立空间，尺寸可自定义宽高。图表和素材都放在画布上。
- **图表资产（Asset）**：保存到图表库的成品 = 画布尺寸 + 图表 + 素材 + 元信息（名称、分类、标签、缩略图）。
- **副本**：从图表库使用资产时，生成一份独立的新图表。修改副本不影响库中资产，修改库中资产也不影响已生成的副本。

## 四、用户流程

### 4.1 新建并制作图表

1. 在图表库点击「新建图表」，选择图表类型，设置画布尺寸（宽、高，可自定义）。
2. 进入图表编辑空间（独立画布）。
3. 在右侧面板配置图表参数（分组表单，附中文说明和取值限制）。
4. 在数据表格中编辑假数据（可粘贴 Excel 数据）。
5. 从左侧拖入素材（文本、图片、形状、背景），在画布上装饰和排版。
6. 通过图层面板调整层级，锁定或隐藏不需要的元素。
7. 点击「保存到图表库」，填写名称、分类、标签，系统自动生成缩略图。

### 4.2 复用图表

1. 在图表库搜索或按分类、标签筛选。
2. 对资产执行「编辑」：生成一份副本并打开编辑；或「复制」：生成副本到库中。
3. 修改副本，保存后只影响这份副本。

### 4.3 演示

1. 在图表编辑空间或图表库中点击「演示」。
2. 图表全屏铺满，隐藏所有编辑界面。
3. 退出演示模式。（具体交互见第七节）

## 五、界面与交互

> 本节的界面布局是基于前期讨论的建议方案。最终以评审为准。

### 5.1 页面结构

| 页面 | 作用 |
|---|---|
| 图表库 | 图表卡片网格，搜索与分类筛选，新建、编辑、复制、删除、导出，进入演示 |
| 图表编辑（独立画布） | 核心编辑页，三栏 + 顶栏 |
| 演示模式 | 全屏只读展示 |

顶部导航：图表库 / 图表制作。（第二阶段再增加「大屏」入口。）

### 5.2 图表编辑页布局

```
┌──────────────────────────────────────────────────────────┐
│ 顶栏：图表名 · 保存状态 · 撤销 重做 · 演示 · 保存到图表库   │
├──────────┬─────────────────────────────┬─────────────────┤
│ 左栏      │ 画布区                        │ 右栏（检查器）    │
│ 图表类型   │  独立画布（自定义宽高）          │ 未选中：画布属性   │
│ 素材      │                             │ 选中素材：位置尺寸  │
│ 图层      │                             │ 选中图表：参数配置  │
│          │                             │ 数据：表格         │
└──────────┴─────────────────────────────┴─────────────────┘
```

- **左栏**：标签页「图表类型 / 素材 / 图层」。素材拖入画布即添加。
- **画布区**：默认适应窗口，画布外为灰色区域。底部显示缩放比例（可选择档位）和画布尺寸。
- **右栏**：根据当前选中内容显示对应面板，分组可折叠，常用项在前。
- **最小宽度**：1280px。窄屏时右栏可收起。

### 5.3 关键交互

| 功能 | 交互设计 |
|---|---|
| 拖入素材 | 拖到画布任意位置落位；拖动时显示半透明预览；落位后自动选中 |
| 选择 | 点击选中；框选只能从空白处开始；Shift 加选；Esc 取消 |
| 移动与吸附 | 拖动时显示对齐参考线（画布边缘、中心、其他素材边缘）；按住 Alt 临时关闭吸附 |
| 缩放与旋转 | 8 个手柄，Shift 等比缩放；旋转时显示角度；检查器可直接输入数值，并与拖动保持同步 |
| 图层 | 拖拽排序，置顶、置底、上移、下移；锁定后不可框选或拖动，但仍可在图层面板中选中；隐藏；双击重命名 |
| 图表参数 | 分组表单（标题、图例、提示、网格、坐标轴、系列等）；每项有中文说明；错误就地提示，不只是标红 |
| 数据表格 | 类似电子表格：单击输入，Tab 和回车切换单元格；Ctrl+V 粘贴 Excel 数据，自动扩行；粘贴后显示「已识别 N 行 × M 列」 |
| 撤销与重做 | Ctrl+Z / Ctrl+Shift+Z，覆盖所有编辑（包括参数面板中的修改） |
| 保存 | 自动保存（防抖），顶栏显示保存状态；手动「保存到图表库」用于生成资产 |
| 复制 | Ctrl+C / Ctrl+V 复制素材；Ctrl+D 原位复制 |
| 组合 | Ctrl+G 组合，Ctrl+Shift+G 解组 |
| 图表库操作 | 卡片：打开编辑、演示、复制、导出（JSON）、编辑信息（名称/分类/标签）、删除（需确认） |

### 5.4 空状态与引导

- 图表库为空时，显示「新建图表」按钮和一句说明。
- 不设置模板市场。

## 六、功能与数据

### 6.1 图表类型与参数

- 沿用原项目的 6 种图表。
- 参数面板按组件分组：标题、图例、提示框、网格、坐标轴、系列、颜色等。
- 参数最终生成 ECharts `option` 的覆盖层，原项目已有的参数 schema 可复用。

### 6.2 素材类型

| 素材 | 可配置项 |
|---|---|
| 文本 | 内容、字号、颜色、对齐、字重、行高 |
| 图片 | 来源（本地上传）、填充方式（包含、覆盖、拉伸） |
| 形状 | 矩形、椭圆、线条；填充、描边、描边宽度、圆角 |
| 背景 | 纯色、渐变（起止色、角度）、图片 |

- 图片导入时压缩（长边不超过 2048px，JPEG，不超过 2MB），避免撑爆本地存储。

### 6.3 图表库中的资产结构（概念）

```
Asset {
  id, name, category, tags[],
  thumbnail,                 // 自动生成的缩略图
  canvas { width, height, background },
  chart { type, option, data },    // data 为假数据
  decorations[],             // 文本、图片、形状（含背景）
  createdAt, updatedAt
}
```

### 6.4 存储

- 第一阶段使用浏览器本地存储（localStorage），不依赖后端，不做账号。
- 自动保存，防抖。
- 注意：本地存储容量有限，图片素材需要压缩；需要在界面上提示存储空间不足。

## 七、演示模式

已确认：第一阶段包含演示模式，对图表（以及后续的大屏）都适用。

**已确认的内容：**
- 全屏铺满，隐藏所有编辑界面。
- 画布等比缩放适配屏幕，保持比例。

**已确认定稿：** 退出方式：Esc 键或点击屏幕右上角浮动退出按钮（鼠标闲置约 3 秒自动隐藏）；画布等比缩放适配屏幕并居中，比例不一致时周围留黑边；不设播放控制。

## 八、非功能要求与验收

### 8.1 验收标准（第一阶段）

1. 能在 5 分钟内完成「新建 → 配置参数 → 编辑假数据 → 添加素材 → 保存到图表库」的完整流程。
2. 图表库中保存的图表，刷新页面后数据仍在。
3. 从图表库编辑或复制的副本，修改后不影响原资产。
4. 演示模式可全屏展示图表和素材，退出后回到编辑界面。
5. 撤销与重做覆盖参数修改、素材移动、数据编辑。
6. 质量门：类型检查、单元测试、生产构建全部通过。

### 8.2 非功能要求

- 技术栈沿用现有：Vue 3 + TypeScript + Vite + Pinia + Element Plus + ECharts 6 + Vitest。
- 核心逻辑（数据模型、存储、历史记录、几何计算）独立于 UI 组件，便于单元测试。
- 界面语言：中文。
