# DataV 7.0 PC 端画布编辑器功能参考

> **文档性质**：对阿里云 DataV 7.0 官方帮助文档的中文归纳，供 ChartForge 的产品设计与功能拆分参考；不是 DataV 操作手册的逐段翻译，也不表示本文列出的能力均已在 ChartForge 实现。  
> **整理日期**：2026-10-30  
> **范围**：从“PC 端画布编辑器”入口出发，覆盖其编辑器布局、左侧功能面板、画布组件操作、右侧组件配置，以及与这些功能直接相关的主题、美化、预览发布、变量和过滤器文档。具体组件的逐项配置说明不在本文范围内。

## 1. 编辑器定位与基本流程

DataV PC 画布编辑器以“在画布上组织可视化组件”为中心：从组件库或设计资产中添加内容，在画布上完成定位、排版和样式设置，为组件绑定数据并配置联动，最后预览、调试和发布看板。编辑器周边面板分别承载组件组织、资产复用、变量与过滤器、历史状态及数据源管理。

官方文档给出的常见入口是：登录 DataV 控制台，在工作台/全部应用中找到目标数据看板，选择“编辑”进入画布编辑器。

**典型搭建路径**

1. 新建或打开一个看板。
2. 从组件库、设计库添加组件或设计资产。
3. 通过画布与图层面板定位、编组和排版。
4. 在右侧配置样式、数据源及高级能力。
5. 需要跨组件传值时配置全局变量；需要转换数据时配置过滤器；需要复杂联动时进入蓝图编辑器。
6. 预览或调试，确认后发布并管理快照。

## 2. 编辑器界面与功能分区

### 2.1 顶部工具栏

工具栏集中放置编辑器级操作，官方说明涵盖：

- **美化工具箱**：统一访问一键美化、主题等视觉整理能力。
- **滤镜与全局搜索**：快速进入筛选/搜索，定位组件、配置或相关对象。
- **画布 / 蓝图切换**：在可视化排版与节点式交互编排之间切换；从组件或图层进入蓝图时可定位到相应节点。
- **画布管理**：刷新画布、显示或隐藏面板等编辑器视图控制。
- **主题设置与错误提示**：配置主题，并查看编辑器提示的错误信息。
- **帮助入口**：提供新手引导、快速链接及功能说明，便于查找操作帮助。
- **预览、调试预览与发布**：普通预览用于检查呈现效果；调试预览侧重查看交互日志和组件运行错误；发布用于对外展示或分享看板。
- **快照**：保存、预览、锁定/解锁、发布或删除画布快照，作为发布版本和画布状态管理手段。

### 2.2 左侧功能面板

| 面板 | 功能介绍 | 适合解决的问题 |
| --- | --- | --- |
| 图层 | 以树形结构查看画布组件、组及容器；调整顺序、可见性、锁定状态，进行编组、重命名、复制、删除、收藏等操作。 | 组件重叠、层级难找、需要批量组织或复用组件。 |
| 组件库 | 浏览组件分类、搜索组件、切换可用组件包并将组件加入画布。 | 从基础图表、指标或装饰类组件快速搭建页面。 |
| 设计库 | 管理和复用成套设计资产、模板/视觉资源及个人收藏。 | 需要统一风格、复用已有页面资产或个人组件组合。 |
| 全局变量 | 创建、管理看板级变量，供组件之间传递参数和驱动更新。 | 筛选器、查询参数或交互事件需要影响多个组件。 |
| 过滤器 | 配置可复用的数据处理逻辑，并在组件数据源或蓝图等场景中应用。 | 数据源返回结构需要转换、清洗或按条件处理。 |
| 历史记录 | 查看并回退到历史状态，或清空历史记录。 | 误操作后恢复较早的编辑状态。官方文档提示刷新页面会清空历史。 |
| 数据管理 | 汇总看板数据源类型、数量和关联组件，并支持配置单项或批量变更数据来源。 | 盘点数据依赖、批量调整数据源或检查组件与数据源关联。 |

### 2.3 中央画布与组件交互

画布提供所见即所得的组件编辑区域，主要操作包括：

- **交互模式**：可临时模拟组件交互，用于检查看板联动；退出时按界面提示刷新以恢复编辑状态。官方说明该模式下不能使用画布缩放。
- **添加与选择**：从组件库拖入组件；单击选择单个组件，按 Ctrl/Cmd 单击进行多选；也可以在图层树中用相同方式选择。
- **几何变换**：拖动组件调整位置，拖拽边界框调整尺寸，拖动旋转控制点旋转组件；可通过配置面板精确输入位置、尺寸和角度，也可翻转组件。
- **层级与对象操作**：置顶、置底、上移/下移一层、隐藏/显示、锁定、重命名、复制 ID、复制、删除和收藏。
- **分组与批量编辑**：多选组件后对齐、水平/垂直均分，统一调整位置和尺寸；满足组件类型及版本条件时，可批量设置统一样式。
- **缩略图与缩放**：通过缩放控件调整画布比例；缩略图帮助快速导航到超出当前视口的组件区域。
- **坐标与辅助线**：显示组件相对于画布的坐标，可通过标尺建立/隐藏辅助线，并利用组件间对齐线与距离标注辅助排布。
- **快捷操作**：包含鼠标选择、多选、右键操作菜单与 Ctrl/Cmd+F 全局搜索等。

### 2.4 右侧配置面板

未选中组件时，面板用于页面级配置；选中组件后，面板切换为组件配置，主要分为：

- **页面设置**：调整画布尺寸（官方默认值为 1920×1080 px）、背景颜色与透明度、预览/发布页的缩放方式、背景自动填充及组件加载状态；也可截取或上传看板封面。上述默认值和选项以官方页面当前版本为准。
- **样式**：提供快速样式/快捷配置与完整属性配置。常见通用属性包括尺寸、定位、旋转、不透明度等；可搜索配置项，快速跳转到目标属性，并可复用/粘贴样式。
- **数据源**：选择组件数据来源，配置请求或数据输入、字段映射及过滤处理。
- **高级**：按组件能力配置交互事件、全局变量等高级参数；复杂联动可以在蓝图编辑器中继续编排。

属性项会随组件类型而不同，应以当前选中组件的配置面板为准。

## 3. 重点功能说明

### 3.1 图层、分组与迭代器

图层树既是画布对象的目录，也是管理层级和选择对象的入口。除了排序、锁定、隐藏、重命名、复制/删除和收藏，还支持展开或收起组/容器、在蓝图中定位组件等操作。

组件成组后可作为整体排布；迭代器则把组作为列表生成容器，由数组驱动重复内容，生成数量随输入数组长度变化。官方文档注明迭代器绘制上限为 100 个单元，并提供背景、超出滚动和滚动条等设置。

### 3.2 轮播容器

轮播容器将多个组件放在固定区域内，通过滑动、淡入淡出、翻转等动效切换，适用于屏幕空间有限但需要轮流展示多个内容的场景。可从多选组件创建，也可解除容器恢复为独立组件。

配置范围包括动画样式、方向、时长、背景、间距、可视/轮播数量、自动播放、鼠标悬停暂停、视差，以及启动/暂停等控制；高级配置可关联交互事件和全局变量。一个组件只能属于一个轮播容器。

### 3.3 数据源、映射与过滤器

组件数据可来自静态数据、全局变量或业务数据源。组件数据源配置用于将输入数据连接到组件预期结构；当结构不匹配时，可用字段映射和过滤器进行适配。官方文档说明数据经过过滤器处理后再进行映射；可按需配置请求自动更新和相关加载行为。

过滤器可被管理、排序、调试，并按顺序级联处理数据。共享过滤器被多个组件引用时，修改或删除它可能影响所有依赖组件，维护时需要检查引用关系。全局变量的使用示例涵盖静态值、异步请求、URL 查询参数、交互事件参数及过滤器引用；官方示例特别指出静态数据或 CSV 数据源不支持全局变量引用，具体限制应以原文和实际组件能力为准。

### 3.4 全局变量

全局变量是跨组件传递参数的公共状态入口。管理能力包括设置来源和初始值、绑定过滤器、受控模式与自动更新属性，以及重命名、复制和删除。使用时要考虑变量的来源、更新时机和被哪些组件引用，避免无意触发不必要的数据请求。

### 3.5 主题与一键美化

- **智能主题**：可使用内置配色或从自定义图片生成主题，并统一调整图表颜色与文字样式（字体、粗细、字号、颜色、图表复杂度等）。主题会应用到支持该能力的组件及看板背景；并非所有组件都支持主题。
- **一键美化**：按预设整体样式和布局规则，批量调整看板内容，包括标题/背景样式、边距、组件对齐与吸附阈值等。适合快速获得一致的视觉基线，但官方明确提示应用后可能覆盖原有配置并改动组件，执行前应先预览并确认。

### 3.6 预览、调试、发布与快照

- **普通预览**：查看看板最终展示效果，不记录交互日志和错误信息。
- **调试预览**：在交互连线上开启日志记录后，可查看蓝图交互节点与数据、组件请求/过滤器/渲染等错误详情；适合联动问题的端到端排查。
- **发布与分享**：发布看板后可通过链接或二维码分享，并按需要设置密码、Token 验证、IP 白名单、分享卡片信息或加载页等访问与展示属性。访问安全参数应依据实际风险配置。
- **快照管理**：保存画布状态，支持预览、锁定、发布/关闭发布以及删除；已发布快照的删除受限制。不同版本的快照数量上限可能不同，本文不固定记录易变的套餐数值。

## 4. 面向 ChartForge 的参考拆分

本节是结合 ChartForge 定位给出的产品建议，不属于阿里云官方定义。

| 能力域 | 可借鉴的产品抽象 | ChartForge 实施边界/提醒 |
| --- | --- | --- |
| 画布编辑 | 组件选择、拖拽、尺寸/位置、对齐、缩放、层级、缩略图、撤销历史。 | 持久化为可验证的项目数据；按产品既定规则实现快捷键与辅助线反馈。 |
| 组件与资产 | 分类目录、搜索、收藏、模板/设计资产复用。 | 首发组件和素材使用编译期受控注册，不加载任意用户代码或运行时插件。 |
| 属性配置 | 页面级与组件级配置分开；按 schema 展示样式、数据、进阶项。 | 配置应由受控 schema 和组件定义驱动，避免动态执行表达式。 |
| 数据链路 | 数据源 → 过滤/转换 → 字段映射 → 组件；变量驱动联动更新。 | 过滤器应是受限、可组合的数据操作；不使用 `eval`，不要把 DataV 的在线/云服务依赖直接带入离线导出。 |
| 视觉统一 | 主题 token、批量样式、布局建议与一键排版。 | 自动美化应可预览、可撤销；导出所需字体/图片等资源应可离线获取。 |
| 发布与调试 | 普通预览、交互调试日志、导出/发布版本和快照。 | 优先支持本地预览和离线交付；任何联网服务必须是可选能力，不应成为导出运行条件。 |

以上边界与 ChartForge 当前约束一致：Vue 3 + TypeScript 技术栈、编译期受控注册、无运行时用户代码/插件、离线导出不依赖外部网络资源、禁止 `eval`。因此本文用于功能参考，不建议逐项照搬云端产品的服务依赖或扩展机制。
